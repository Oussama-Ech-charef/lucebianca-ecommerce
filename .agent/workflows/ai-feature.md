# AI Feature Workflow

## Related Skills

`ai-integration`, with `security`, `backend`, `database`, and `quality-assurance` as required.

1. Define the user value and a non-AI fallback.
2. Identify data sources, sensitive data, retention, and privacy boundaries.
3. Choose the provider and keep the integration replaceable where useful.
4. Define input boundaries, prompt layers, output schema, source attribution, and limits.
5. Add timeout, retry, rate-limit, fallback, and failure behavior.
6. Validate outputs before they reach users or downstream systems.
7. Test malformed input, unavailable providers, unsafe output, hallucination, and missing sources.
8. Document cost, operational assumptions, and known limitations.
