# Ship Workflow

## Related Skills

`devops` and `quality-assurance`, with `security`, `database`, `documentation`, or `agent-browser` for browser smoke tests as required.

1. Confirm acceptance criteria and required checks.
2. Run tests, linting, type checks, builds, and packaging as appropriate.
3. Review configuration, secrets, migrations, compatibility, and rollback steps.
4. Confirm logs, monitoring, health checks, and release ownership.
5. Deploy through the project’s approved path.
6. Run smoke tests and inspect operational signals.
7. Roll back when defined safety conditions are met.
8. Record the release result, known issues, and follow-up work.
