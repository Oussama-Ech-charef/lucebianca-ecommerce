# Discover Workflow

## Related Skills

`project-discovery`, with `requirements-analysis`, `architecture`, and `find-skills` when a capability is missing.

1. Locate the project root and repository boundaries.
2. Read instructions, README files, manifests, configuration, entry points, and relevant scripts.
3. Inventory source, tests, documentation, infrastructure, generated files, and sensitive paths.
4. Detect the stack using evidence and confirm signals in code or configuration.
5. Trace relevant data flow, external services, build commands, and test commands.
6. Record conventions, unknowns, risks, and likely affected areas.
7. Produce a discovery report before making a broad change.
