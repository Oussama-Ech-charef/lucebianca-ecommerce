# Verify Workflow

## Related Skills

`quality-assurance`, with `security`, `accessibility-internationalization`, `documentation`, `tdd`, `web-design-guidelines`, or `agent-browser` as required.

1. Review the changed files and the final diff.
2. Run the nearest focused tests.
3. Run linting, type checks, formatting checks, and the build when available.
4. Check permissions, validation, errors, empty states, loading states, and boundary cases.
5. Check for secrets, unsafe logs, regressions, accessibility problems, and performance hazards.
6. Record passed, failed, skipped, and unavailable checks.
