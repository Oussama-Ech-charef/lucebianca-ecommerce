# Feature Delivery Workflow

## Related Skills

`requirements-analysis`, `architecture`, and `quality-assurance`, plus `grill-me`, `tdd`, `code-review`, and the domain skills required by the feature.

1. Define the goal, users, acceptance criteria, and non-goals.
2. Discover the existing project and trace the affected path.
3. Choose the design, dependencies, risks, and required skills.
4. Plan the smallest vertical slice and its checks.
5. Implement the minimum complete behavior.
6. Cover security, validation, accessibility, errors, empty states, and compatibility.
7. Run verification and inspect the final diff.
8. Update relevant documentation and provide a traceable handoff.
