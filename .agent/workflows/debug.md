# Debug Workflow

## Related Skills

`project-discovery`, `quality-assurance`, and `diagnosing-bugs`, plus the domain skill or `agent-browser` for browser-specific failures.

1. Capture the exact symptom, expected behavior, environment, and reproduction steps.
2. Inspect logs, stack traces, recent changes, configuration, and relevant data flow.
3. Reproduce the issue with the smallest reliable case.
4. Form explicit hypotheses and test them one at a time.
5. Identify the root cause rather than masking the symptom.
6. Implement the smallest safe fix with no unrelated refactor.
7. Add or update a regression test.
8. Verify the original reproduction case and nearby edge cases.
9. Record the cause, fix, verification, and any remaining risk.
