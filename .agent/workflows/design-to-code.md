# Design-to-Code Workflow

## Related Skills

`product-design` and `frontend`, with `accessibility-internationalization`, `mobile`, `web-design-guidelines`, or `agent-browser` as required.

1. Understand the product goal, users, content, and key journey.
2. Inspect the existing design system, tokens, components, and responsive rules.
3. Define information architecture, zones, states, and wireframe structure.
4. Reuse existing components or define only the missing primitives.
5. Create the visual direction or prototype using real content and states.
6. Implement semantic, responsive, accessible components.
7. Integrate the behavior and test loading, empty, error, and success states.
8. Perform visual and functional verification across relevant viewports.
