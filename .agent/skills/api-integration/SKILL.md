# API Integration

Discover the protocol, authentication, schemas, versioning, timeouts, retries, rate limits, pagination, webhooks, idempotency, error mapping, and data privacy requirements.

Validate external responses, isolate provider-specific code, avoid leaking credentials, handle partial failure and duplicate delivery, and make retry behavior safe. Document the contract, required configuration, failure modes, and observability.

Test success, invalid input, unauthorized access, missing resources, provider errors, timeouts, malformed responses, rate limits, retries, and webhook replay where relevant.
