# Accessibility and Internationalization

Check semantic structure, keyboard navigation, focus management, labels, contrast, motion, screen-reader output, error announcements, touch targets, and meaningful alternatives for non-text content.

Check translation boundaries, text expansion, pluralization, dates, numbers, currencies, time zones, locale-sensitive sorting, Unicode, font support, and right-to-left layouts when relevant.

Use the project’s existing tools and conventions. Verify representative locales and assistive interaction paths instead of relying only on visual inspection.
