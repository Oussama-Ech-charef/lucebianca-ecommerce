# Project Management

Use MVP boundaries, MoSCoW prioritization, milestones, dependency mapping, a risk register, a decision log, and a clear definition of done.

Keep out-of-scope work visible. Tie each task to a verifiable output, surface blockers early, and manage scope changes explicitly instead of silently expanding the project.
