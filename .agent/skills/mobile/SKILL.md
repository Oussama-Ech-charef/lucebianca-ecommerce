# Mobile

Discover whether the project uses Flutter, React Native, Android, iOS, Kotlin, Swift, or another mobile stack. Inspect navigation, state management, platform permissions, offline behavior, storage, networking, build configuration, and release targets.

Consider small screens, touch targets, keyboard and screen-reader support, lifecycle changes, slow networks, low memory, orientation, platform conventions, secure storage, and error or offline states.

Reuse existing components and patterns. Verify behavior on the relevant platforms and record what was tested on real devices, emulators, or simulators.
