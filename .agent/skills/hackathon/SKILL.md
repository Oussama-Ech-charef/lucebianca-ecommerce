# Hackathon

Define the problem, target user, shortest valuable journey, one differentiator, and a reliable demo path. Score ideas by feasibility, impact, differentiation, and technical depth.

Use a build loop of thin vertical slice, early integration, verification, deployment, and demo rehearsal. Keep a backup demo path and freeze scope once the core journey is reliable.
