# DevOps

Discover package scripts, build and test commands, containers, CI/CD, hosting, environment variables, logs, metrics, health checks, and rollback mechanisms.

Never commit secrets. Keep development, CI, staging, and production assumptions explicit. Build before deployment, verify health after deployment, preserve a rollback path, and avoid solutions that work only on one machine.
