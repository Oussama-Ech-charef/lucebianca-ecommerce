# Patterns

Prefer SOLID, DRY, KISS, separation of concerns, composition, and dependency inversion where they improve the affected code.

Consider Repository for persistence boundaries, Strategy for replaceable behavior, Adapter for incompatible interfaces, Factory for controlled construction, Observer or events for decoupled notifications, Decorator for layered behavior, and dependency injection for explicit collaborators.

Explain the problem a pattern solves and its cost. Do not add patterns for their own sake.
