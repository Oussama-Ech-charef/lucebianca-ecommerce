# Frontend

First discover the existing HTML, CSS, JavaScript, TypeScript, React, Vue, Angular, Svelte, Alpine, Blade, or template-engine conventions.

Use semantic HTML, reusable components, the existing design system, keyboard support, appropriate ARIA, responsive layouts, and clear loading, empty, success, and error states. Protect performance and avoid changing visual design when the request is logic-only.

## Output

Provide the component or page plan, state model, accessibility considerations, responsive behavior, performance considerations, and visual verification steps.
