# Agent Lifecycle

## 1. Discover

Resolve the workspace root, Agent configuration path, and project scope first. Then collect configuration files, source code, tests, documentation, scripts, and version-control context.

## 2. Map

Identify languages, frameworks, entry points, modules, data stores, external services, build commands, and test commands.

## 3. Clarify

Define the user goal, scope, expected behavior, acceptance criteria, non-goals, constraints, and risks.

## 4. Plan

Choose the smallest safe implementation path. Record affected files, change order, checks, and rollback considerations.

## 5. Execute

Apply focused changes while preserving existing conventions, compatibility, and unrelated work.

## 6. Verify

Run the most relevant static checks, tests, builds, and manual checks. Record the exact commands, scope, environment, results, and what was not verified.

## 7. Handoff

Summarize the result, changed areas, verification evidence, known limitations, and recommended next step.
